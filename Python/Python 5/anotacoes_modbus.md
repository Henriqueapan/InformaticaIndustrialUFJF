# MODUBS

## Tabela MODBUS

* Cada dispositivo conectado tem uma tabela daquelas. Os endereços representam de fato valores individuais com o tamaho de dado representando na linha da tabela
* Diferentes tabelas (de dispositivos diferentes) são independentes entre sí

## Utilização do Function code

* Em conjunto com o atributo "data", é possível estruturar a requisição para o servidor
